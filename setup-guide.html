TaskFlow Setup Guide

Follow these 5 steps once to connect your dashboard to Google Sheets. Takes about 10 minutes.

1

Create a Google Sheet

  1. Go to sheets.google.com and create a new spreadsheet
  2. Name it TaskFlow Data (or anything you like)
  3. Create these 3 sheets (tabs at the bottom):
    • 📋 Tasks
    • 👥 Users
    • 🏷️ Categories
  4. In the Users sheet, add headers in row 1: Username | Password | DisplayName | Active
  5. Add your first user in row 2, e.g: admin | yourpassword | Admin | true
  6. In the Categories sheet, add header Category in row 1, then list your categories below (one per row)

EXAMPLE CATEGORIES:

Work, Personal, Dev, Marketing, Design, Operations, Admin

2

Copy the Sheet ID

Your Sheet URL looks like this:

https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms/edit

Copy the long ID between /d/ and /edit

3

Set up Apps Script

1. In your Google Sheet, click Extensions → Apps Script

2. Delete all existing code in the editor

3. Open Code.gs from the files you downloaded and paste the entire contents

4. Find line 3: const SHEET_ID = 'YOUR_GOOGLE_SHEET_ID_HERE';

5. Replace YOUR_GOOGLE_SHEET_ID_HERE with your actual Sheet ID from Step 2

6. Click 💾 Save

4

Deploy as Web App

1. Click Deploy → New deployment

2. Click the gear icon ⚙ next to "Select type" → choose Web app

3. Set:

  • • Execute as: Me
  • • Who has access: Anyone

4. Click Deploy → Authorize when asked

5. Copy the Web app URL — it looks like:

https://script.google.com/macros/s/AKfycb.../exec
5

Connect to Dashboard

1. Open index.html in your browser

2. On the login screen, tap ⚙ Configure Google Sheets

3. Paste your Web App URL and tap Save & Connect

4. Log in with the username/password you added to the Users sheet

5. ✅ Done! All tasks will now sync to your Google Sheet in real time.

🚀 Hosting on GitHub Pages (Free)

  1. Create a free account at github.com
  2. Create a new repository (e.g. taskflow)
  3. Upload index.html and setup-guide.html
  4. Go to Settings → Pages → Source: main branch
  5. Your app will be live at https://yourusername.github.io/taskflow

Access it from any device, anywhere in the world!

👥 Adding More Users

To add more users, simply add rows in the Users sheet:

UsernamePasswordDisplayNameActive
alicepass123Alicetrue
bobsecure99Bobtrue

Set Active to false to disable a user without deleting them.

📤 Bulk Upload Format (.txt)

Create a .txt file with one task per line, fields separated by |:

Task Name | Category | Priority | Time | Notes (optional)
Fix login bug | Dev | High | 1 hour | Check auth module
Write blog post | Marketing | Low | 2 hours
Review designs | Design | Medium | 30 min | Figma link in Slack
Deploy to staging | Dev | High | 4 hours

Priority: High, Medium, or Low · Time: 30 min, 1 hour, 2 hours, 4 hours, or 1+ day
